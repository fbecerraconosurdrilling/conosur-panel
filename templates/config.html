✉️ Enviar email de prueba

📤 Enviar informe manual

Ejecuta un control ahora mismo: consulta las cámaras, aplica las reglas de grupo y envía el informe con el formato corporativo completo, con el listado real de cámaras caídas.

Importante: este envío también guarda el log de control correspondiente, igual que un control programado.
